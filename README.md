# ECON 615: Computational Economics

Lecture notebooks for the course. You do not need to download anything from
this page: use the link posted for each lecture, which opens the notebook in
your own Syzygy workspace.

## Each lecture

1. Click the lecture link. The notebook opens on Syzygy.
2. Run the **first cell** of the notebook. It turns on the course reporter.
3. Work through the exercises.

If you restart the kernel, run the first cell again.

## What the course reporter sends

After each cell you run, `course_reporter.py` sends your instructor: your name,
the lecture, the cell number, whether it ran without problems, the error or
warning message, and, only when there is a problem, the code of that cell.
Nothing else is sent. This lets the instructor and TA see during class who is
stuck, so we can help you faster.

## Your work is safe

When a lecture link is clicked again later (for example, after the notebook was
updated), your own changes are kept.
